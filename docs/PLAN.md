# Classeum 기획서

> 운동장에서 함께 푸는 영단어·문법 퀴즈. 중2 방과후 영어, 매주 30~40명, 학생마다 폰 1대.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 퀴즈 | 영단어 맞히기와 문법 문제. 한 번에 20~50문항, 빠르게 |
| 화면 연결 | 노트북 확장 모드: 노트북 = 진행 콘솔, 프로젝터 = 운동장 |
| 생성형 AI | 쓰지 않음. 문제와 오답 보기는 정해진 규칙으로 만든다 |
| 문제 입력 | 엑셀 `단어장` 시트나 [직접 작성하기]에 단어·뜻만 쓰면 앱이 문제와 오답 보기를 만든다. 문법은 문법 탭 4개(고르기·쓰기·고치기·배열)에 워크시트처럼 쓴다. 세트(없으면 파일) 1개 = 이벤트 1개 |
| 운동장 | 폰의 큰 답 칸을 누르면 내 캐릭터가 그 칸으로 쏙. 답하는 동안 큰 화면은 안개, 마감 순간 안개가 걷히며 전원 공개 |
| 시간 | 문항당 기본 10초(단답형 20초). 모두 답하면 일찍 마감. 마감 순간 서 있는 칸이 답 |
| 진행 | 자동 진행. 선생님은 멈춤·지금 공개·+5초·건너뛰기·화면 가리기·종료 |
| 보상 | 오늘의 보상(미리 공개, 원정 첫 답 기준) + 출석 발자국. 속도 점수·순위·탈락 없음 |
| 마무리 | 학생 폰에 오답 노트 + 틀린 단어 다시 풀기. 선생님은 학생별·단어별 통계 |
| 캐릭터 | 자체 24×24 픽셀 캐릭터. 머리 모양 12·머리색 7·피부색 4·눈 5가지에서 고른다. 성별은 저장하지 않음 |

## 2. 화면은 3개

| 주소 | 기기 | 하는 일 |
|---|---|---|
| `/teacher` | 선생님 노트북 | 직접 작성하기 또는 엑셀 올리기 · 미리보기 · 보상·오늘 반 고르기 · 등록 승인 · 진행 · 통계 |
| `/display` | 프로젝터 | 대기실(QR·들어온 캐릭터·오늘의 보상·놀이 방법 시범) · 운동장(안개 → 공개) · 관문 · 마무리 요약 |
| `/play` | 학생 폰 | 첫 등록·캐릭터 고르기 · 큰 답 칸 · 정답 확인 · 오늘 결과 · 오답 노트 · 보관함 |

## 3. 핵심 흐름

### 3.1 이벤트 만들기

1. 엑셀을 올리거나 [직접 작성하기]에 제목과 단어·뜻(예문은 선택)을 쓴다. 직접 작성은 엑셀·한글 표에서 여러 줄을 붙여 넣을 수 있고, 쓰던 내용은 노트북 브라우저에 남는다. 단어장 시트와 같은 규칙으로 검사한다(행 번호는 화면의 줄 번호).
2. 미리보기: 검사 결과(오류·경고 개수, 시트·행·칸과 고칠 방법)와 만들어질 문제 전체를 정답과 함께 보여 준다. 오류가 있으면 엑셀을 고쳐 다시 올리거나 [고치기]로 돌아간다.
3. [이벤트 만들기]. 이름은 세트 칸 값, 비어 있으면 엑셀 파일 이름(`3주차 단어장.xlsx` → `3주차 단어장`), 직접 작성은 제목(비면 `10-26 퀴즈`처럼 날짜). 같은 이름이 있으면 `(2)`를 붙인다.
4. 이벤트마다 문항 수, 문항당 시간, 예상 소요 시간을 보여 준다. 한 이벤트를 여러 반에서 돌아가며 연다. 목록과 상세에 이미 한 반(초록)과 아직 안 한 반(회색)이 나오고, 고른 반이 이미 했으면 대기실을 열기 전에 알려 준다.
5. [엑셀로 받기]: 이벤트의 단어를 템플릿 모양 엑셀로 내려받는다(직접 작성 창과 이벤트 상세).

### 3.2 반과 첫 등록

선생님은 여러 반을 맡는다 (예: 6개 반, 학생 180명 이상, 한 번에 접속은 30명 안팎). 반마다 학생이 따로 있고 번호(1~99)는 반 안에서만 겹치지 않으면 된다. 같은 이벤트를 여러 반이 각자 진행하고, 기록·통계는 반별로 남는다. 보상·아이템·발자국은 반과 상관없이 학생 개인 것이다.

0. 선생님이 대기실을 열 때 오늘 반을 고른다. 그 반 학생만 등록·입장하고, 다른 반 학생 폰은 "지금은 ○반 수업 중"만 본다. 다른 반의 대기 중인 요청은 취소된다.
1. QR을 찍는다 → 반을 고르고(대기실이 열려 있으면 그 반으로 정해져 있다) 번호와 이름을 직접 쓴다. 등록은 선생님 화면이나 프로젝터 화면이 켜져 있을 때만 된다. 등록 전 폰에는 다른 학생 이름을 보여 주지 않는다.
2. 학생 폰과 선생님 화면에 같은 확인 기호(동물 + 두 자리 수, 예: `여우 47`)가 뜬다 → 선생님이 승인한다. 요청은 명단과 비교해 표시한다: 명단 확인(같은 번호·이름) · 새 학생(그 번호가 비어 있음, 승인하면 명단에 추가) · 기기 교체(이미 폰이 있는 학생) · 번호 겹침(그 번호에 다른 이름, 승인하면 이름을 바꾼다). 명단 확인과 새 학생은 [모두 승인]으로 한 번에, 나머지와 "같은 이름이 다른 번호에 있음"은 '따로 확인' 표시를 달고 하나씩 확인한다. 요청은 학생 폰이 대기 화면에 있는 동안 유지되고, 폰이 떠나면 2분, 길어도 15분 뒤 만료된다. 명단을 미리 넣는 건 선택이다.
3. 캐릭터를 고른다 (머리 모양, 머리색, 피부, 눈 탭). 나중에 보관함의 [머리·눈 바꾸기]로 바꿀 수 있다.
4. 다음 주부터는 QR만 찍으면 바로 입장한다 (기기 쿠키는 노트북 주소마다 따로라서 주소가 같아야 한다). 거절되면 다시 쓴다.
5. 새 폰·브라우저 데이터 삭제·노트북 주소 변경: 같은 반·번호·이름으로 보내면 기기 교체로 뜨고, 승인하면 캐릭터와 기록이 이어진다. 학생 한 명에 기기 하나, 새 기기를 승인하면 예전 기기는 풀린다.

### 3.3 한 번의 아레나

| 단계 | 내용 | 시간 |
|---|---|---|
| 대기실 | 입장 QR, 들어온 캐릭터와 이름(이름표를 끄면 캐릭터만), 오늘의 보상 카드. [놀이 방법]을 누를 때만 12초 시범. 선생님 화면의 '오늘 낼 문제'에서 유형(단어 · 문법 고르기 · 쓰기 · 고치기 · 배열 · 보너스 문항, 줄 수와 함께)을 켜고 끈다(하나는 남아야 한다). 문항 수와 예상 시간이 바로 바뀌고, '10문제마다 쉬기'(관문)도 여기서 끈다 | 선생님이 [퀴즈 시작] |
| 원정 | 모든 단어를 한 번씩, 이어서 문법을 고르기 → 쓰기 → 고치기 → 배열 순서로(첫 문법 문제 앞에 2.5초 '이제 문법!' 카드), 예전 파일의 문항 시트 문제는 끝에. 같은 유형 안에서는 순서를 섞는다(고치기 한 줄의 찾기·고쳐 쓰기는 붙여서). 10문항마다 관문(지금까지 반 정답률, 6초 쉬기, 남은 문항이 3개 미만이면 건너뜀) | 문항당 약 13초 |
| 다시 도전 (기본 꺼짐) | 이벤트에서 [끝나고 많이 틀린 단어 다시 풀기]를 켠 날만. 반 정답률 70% 미만 단어 중 낮은 순 최대 5개를 반대 방향(뜻 고르기 ↔ 단어 고르기)으로 다시 | 약 1분 |
| 마무리 | 큰 화면: 반 정답률, 오늘의 보상 받은 친구. 학생 폰: 내 결과, 보상, 오답 노트 | 선생님이 [아레나 닫기] |

예상 시간(앱 계산: 단어 문항마다 최대 9초, 문법 문항은 시간의 80% + 공개 4초, 마무리 1분): 20단어 약 5분, 40단어 약 10분, 50단어 약 12분. 7과 문법 20줄(22문항)은 약 9분. 다시 도전을 켜면 1분 더.

### 3.4 한 문항

| 순간 | 프로젝터 | 학생 폰 |
|---|---|---|
| 등장 (0.6초, 라운드 첫 문항은 3초 동안 3·2·1) | 단어가 위에서 떨어지듯 뜨고, 네 칸(① 파랑 ② 주황 ③ 초록 ④ 보라)에 보기 | 큰 답 칸(같은 색) 위에 "준비!" (라운드 첫 문항은 3·2·1) |
| 이동 (기본 10초) | 흐르는 안개. 칸 이름과 "✓ 31/34"만. 마지막 3초는 시계가 주황으로 깜빡 | 답 칸을 누르면 내 캐릭터가 그 칸으로 폴짝 (진동, 내 위치는 나만). 다른 칸을 누르면 바꿀 수 있다 |
| 마감 | 모두 답 칸을 고르고 1.5초 동안 아무도 누르지 않으면(문항이 열리고 4초, 멈춤을 풀고 3초는 기다림), 아니면 0초에 | 입력 잠김 |
| 공개 (4초) | 안개가 양옆으로 걷히고 캐릭터가 통통 착지. 정답 칸은 금테·월계수 잎, 캐릭터는 하트 내며 폴짝. 오답 칸은 부풀다 "펑!" 하고 그을린 채 어질어질. 몇 명은 말풍선("야호!", "내 머리…") | 내 캐릭터가 크게: 맞으면 폴짝+하트, 틀리면 펑+그을림, 출발선에 남았으면 쿨쿨. 정답, 틀렸으면 "네가 고른 lend = 빌려주다" |
| 다음 | 자동으로 다음 문항. 자동 진행을 끄면 선생님이 [다음] | |

- 반 정답률이 60% 미만이면 공개를 6초로 늘리고 가장 많이 고른 오답을 함께 보여 준다.
- 맞힌 학생이 있으면 공개 순간 프로젝터에서 아이 목소리 "Yeah!"(CC0 녹음 public/sounds/yeah.mp3, 정답률이 높을수록 크게). 참여한 학생이 있는데 아무도 못 맞히면 0.7초 뒤 귀뚜라미 2초(public/sounds/crickets.wav, CC BY 4.0, 출처는 public/sounds/CREDITS.txt). 선생님 화면 [효과음]으로 끄고, 다시 켜면 한 번 들려준다. 브라우저는 클릭한 창에서만 소리를 내므로, 프로젝터 창을 한 번 클릭하거나 키를 누르면(그때 한 번 들려준다) 프로젝터에서, 그 전이나 프로젝터 창이 없으면 선생님 화면에서 소리가 난다. 두 창이 BroadcastChannel로 정해서 한 번만 난다. 선생님 화면 탭이 여러 개 열려 있으면(지난 시간에 열어 둔 탭 등) 마지막으로 클릭한 탭에서만 난다.
- 카운트다운: 이동 단계의 마지막 3초에 나무 블록 틱톡(ultradust "Wood Block Tick Tock", CC BY 4.0, public/sounds/ticktock.wav). 0.5초 간격 6번(3.0·2.5·…·0.5초 남았을 때)으로, 서버 마감 시각에 맞춰 시작한다. 일찍 마감되거나 멈춤이면 바로 끊고, +5초나 다시 시작으로 마감이 바뀌면 새 3초에서 다시 시작한다. [효과음]을 따르고, 나는 창은 다른 효과음과 같다.
- 배경음악: 선생님이 Suno로 만든 노래 「오늘은 내가 정해」(public/sounds/music.mp3, 2분 11초, 끝나면 처음부터)를 대기실부터 결과 화면까지 튼다. 대기실·결과는 0.25, 문제 중(출발·이동·공개·관문)은 0.12로 0.8초 동안 바꾸고, 마지막 3초 틱톡이 나는 동안은 그 0.35배로 줄인다. 멈춤이나 화면 가리기 중에는 0.6초 동안 줄이며 멈추고, 다시 시작하면 멈춘 곳부터 1초 동안 키운다. 선생님 화면 위쪽의 노래 단추(「오늘은 내가 정해 · 켜짐/꺼짐」, 기본 켜짐; 대기실은 제목 아래, 퀴즈 중은 위쪽 막대, 결과는 오른쪽 위)로 끄고 켠다. 어느 창에서 나는지는 효과음과 같다. 노래는 <audio>로 틀고 GainNode로 크기를 바꾼다(2분짜리를 통째로 디코딩하면 창마다 50MB쯤 든다).
- 소리 파일은 MP3와 WAV만 쓴다. 브라우저가 직접 디코딩하므로 윈도우 N/KN처럼 미디어 기능이 빠진 PC에서도 난다(AAC .m4a는 윈도우 디코더에 기대서 빠질 수 있다).
- 쓰기(단답형): 폰이 쓰는 중인 답을 0.3초마다 저장해 두고, 시간이 끝나면 저장된 답으로 채점한다. [제출]을 누른 학생만 "다 했다"로 세서, 모두 제출해야 일찍 마감한다. 프로젝터에는 정답과, 두 명 이상이 같이 쓴 오답만 나온다.
- 이름표(기본 켜짐): 대기실과 정답 공개 때 캐릭터 아래에 이름이 나오고, 공개 때는 틀린 칸의 1~2명과 출발선에 남은 학생(조는 모습)까지 모두 보인다. 그 문항에 접속이 끊긴 학생은 그리지 않는다. 선생님 화면의 [이름표]를 끄면 오답 칸 1~2명은 숫자만, 출발선은 비워서 혼자 펑 터지는 학생이 없게 한다.
- 폰 정답 공개 화면에는 "맞힌 친구 N명"과 맞힌 친구 캐릭터 한 줄(이름 없이 최대 9명, 내가 맞혔으면 맨 앞에 "나")이 나온다. 쓰기 문제는 프로젝터에 누가 맞혔는지 안 나오니 숫자만 보낸다.
- 연속 정답은 내 폰에만: 단어·문법 문제를 2개 이상 연속으로 맞히면 "🔥 N연속", 3연속 이상에서 틀리면 "🔥 N연속 끝". 다시 도전과 직접 쓴 문항은 세지 않고, 접속이 끊겨 쉰 문제는 이어 준다. 결과 화면에 "최고 N연속".
- 대기실 캐릭터는 둥둥 떠 있다가 가끔 혼자 폴짝/빙글, 눈도 깜빡인다. 목록에 서 있는 캐릭터(보상 고르기, 반 관리, 들어온 학생, 캐릭터 고르기, 보관함의 가진 아이템)도 눈을 깜빡이고, 저마다 다른 때에 살짝 폴짝·갸우뚱·두리번한다. 폰 첫 화면 캐릭터는 누르면 한마디 하고, 너무 많이 누르면 빙글 돌며 어지러워한다.
- 선생님 단축키: Space 멈춤 · Enter 지금 공개 · ↑ +5초 · → 다음 · S 건너뛰기 · Shift+S 다음 유형 · B 화면 가리기(시계도 멈춤) · F 프로젝터 전체 화면. 프로젝터 창에서 눌러도 같다. Shift+S만은 선생님 화면에서만 받는다(한 번 더 묻기 때문에, 프로젝터 창에서는 아무 일도 없다). 지금 공개·건너뛰기·다음은 단계가 바뀌고 1초 안에 누르면 무시한다(두 번 눌러 한 문항을 건너뛰지 않게).
- 시간이 모자라면 다음 유형 버튼('문법 고르기로 →'처럼 갈 곳이 쓰여 있다, Shift+S)으로 지금 유형의 남은 문제를 건너뛰고 다음 유형으로 간다. 마지막 유형이면 다시 도전(켜져 있고 다시 낼 단어가 있으면), 아니면 마무리로 간다. 버튼에 갈 곳과 건너뛸 수가 나오고, 누르면 퀴즈를 멈춘 채 한 번 더 묻는다(묻는 사이 다음 유형으로 넘어가 버렸으면 아무것도 건너뛰지 않는다). [종료]는 여기서 마무리한다(낸 문항만으로 결과 저장), 다시 도전만 빼려면 [다시 도전 건너뛰기].
- 건너뛴 문항과 대기실에서 뺀 유형은 기록·보상·통계에서 뺀다. 보상 판정의 '절반'도 실제로 내려던 문항(뺀 것·건너뛴 것 제외)으로 센다.
- 콘솔의 정답은 공개 전까지 가려 두고 [정답 보기]로 연다 (화면이 미러링돼도 새지 않게).

### 3.5 운동장 규칙

- 4지선다: 왼쪽 위 ①, 오른쪽 위 ②, 왼쪽 아래 ③, 오른쪽 아래 ④. OX: 왼쪽 O, 오른쪽 X.
- 문항마다 모두 가운데 출발선에서 시작한다. 마감 때 출발선에 있으면 미응답.
- 폰: 문제 아래 남은 화면을 채우는 큰 답 칸 2개(OX) 또는 4개. 누르면 캐릭터가 그 칸 가운데로 가고, 마감 전까지 다른 칸을 눌러 바꿀 수 있다. 키보드가 있으면 숫자 1~4.
- 안개 중에는 위치가 프로젝터에 안 보인다. 따라가기를 막기 위해서다.
- 공개 때 캐릭터는 칸 안에 줄 맞춰 선다.
- 속도 점수, 순위, 탈락 없음.

## 4. 엑셀 포맷

템플릿: [`templates/M2_L7.xlsx`](../templates/M2_L7.xlsx) (안내 · 단어장(Lesson 7 단어 15개) · 문법 고르기 · 문법 쓰기 · 문법 고치기 · 문법 배열(7과 문법 20줄)). 선생님 화면의 [템플릿 받기]도 이 파일을 내려받고(`/templates/M2_L7.xlsx`, src/app/templates/M2_L7.xlsx/route.ts가 그때그때 읽어 줌), [엑셀로 받기]도 이 파일에 써 넣는다. 사본은 두지 않는다. 표준 xlsx(openpyxl로 만든 파일)라 엑셀·한셀은 물론 AI 도구(openpyxl, pandas)도 연다. 안내 탭 맨 아래에 'AI로 내 파일 만들기' 세 줄과 복사해 쓰는 부탁 글이 있다. 탭마다 늘 쓰는 칸을 왼쪽에(노란 머리글), 필요할 때 쓰는 칸을 그다음에(연회색 머리글) 둔다. 번호 칸은 없다(유형 순서는 정해져 있고, 같은 유형 안에서는 앱이 섞으므로). 거의 안 쓰는 칸(시간(초)·세트·상태·단원·단어ID)은 오른쪽 끝에 회색 글씨로 두고 접어 둔다(표 위 +로 펼침). 단어장과 문법 탭은 표 오른쪽, 고정된 줄 아래에 '이렇게 나와요' 그림 한 장(유형마다 프로젝터와 학생 폰 화면을 나란히, 위아래로 이어 붙임)을 둔다. 앱은 머리글 이름으로 칸을 찾으므로 열 순서와 접기는 상관없다.

### `단어장` 시트 (기본)

| 열 | 필수 | 내용 |
|---|---|---|
| 단어 | ✓ | 영어 단어나 구. 다른 철자는 `color\|colour` |
| 뜻 | ✓ | 한국어. 여러 뜻은 쉼표 (과목, 주제) |
| 품사 | | 명·동·형·부·대·전·접·감·구 (명사·동사처럼 써도 됨) |
| 헷갈리는 단어 | | 오답 1순위. 여러 개는 `;`나 `,`. 단어장에 없는 단어는 `quite(꽤)` |
| 예문 | | 빈칸 자리를 `[ ]`로. `Can I [borrow] your pen?` |
| 예문 뜻 | | 오답 노트에만 |
| 시간(초) | | 비우면 10초 (단답형은 20초) |
| 세트 | | 비우면 파일 이름 |
| 단원 | | 오답 보기 고를 때 참고 |
| 상태 | | 사용(기본) / 검토 / 보관 |
| 단어ID | | 거의 안 씀. 철자가 같고 뜻이 다른 단어만 |

### 앱이 만드는 문제

| 문제 | 예시 |
|---|---|
| 뜻 고르기 | borrow → ① 빌려주다 ② 빌리다 ③ 갚다 ④ 고르다 |
| 단어 고르기 | 빌리다 → ① lend ② bring ③ borrow ④ build |
| 예문 빈칸 | Can I ____ your pen? → ① carry ② borrow ③ lend ④ draw (예문이 있을 때) |

- 단어마다 문제 하나. 처음 나온 단어는 뜻 고르기 60%, 단어 고르기 40%. 전에 나온 적 있는 단어는 단어 고르기와 예문 빈칸이 반반(예문이 없으면 단어 고르기).
- 오답 보기: 헷갈리는 단어(최대 2개)를 먼저, 나머지는 같은 품사·비슷한 철자·비슷한 길이·같은 단원일수록 잘 뽑힌다. 뜻이 겹치는 단어(big/large, 아침/아침 식사처럼 한쪽이 다른 쪽을 포함해도)는 같은 문제에 넣지 않는다. 모자라면 지난 이벤트 단어에서 가져온다. 오답 보기를 2개도 못 만들면 그 단어는 빼고 미리보기에 알린다.
- 예문 빈칸: 괄호 안 글자가 단어와 정확히 같을 때만 만든다(cooks처럼 바뀐 형태면 만들지 않음). 문장에 들어가도 말이 되는 헷갈리는 짝(early/late)은 빈칸 오답으로 쓰지 않는다.
- 정답 위치는 섞되 모두 같은 순서(운동장 칸이 하나니까). 덜 나온 칸에 더 자주 두고, 같은 칸 3번 연속 금지.
- 헷갈리는 짝은 사이에 3문항 이상 두고, 바로 앞 문항의 단어나 정답은 다음 문항 보기에 넣지 않는다.
- 오답 피드백은 자동: 고른 보기의 원래 단어와 뜻을 보여 준다.

### 기록이 이어지는 방식

- 단어 자체(소문자)가 키다. 다음 주에 같은 단어를 올리면 같은 단어로 이어지고, 새로 올린 내용이 예전 것을 대신한다.
- 문제 ID는 `단어:모드` (예: `borrow:MEAN`).

### 문법 탭 4개 (선택)

학생이 하는 일로 나눈다. 단어 다음에 고르기 → 쓰기 → 고치기 → 배열 순서로 나오고(파일 속 탭 순서와 상관없이), 같은 탭 안에서는 앱이 순서를 섞는다. 공통 칸: 지시문(비우면 탭의 기본 지시문), 해설(공개 때 프로젝터에 '규칙' 한 줄로, 폰에도), 시간(초)·세트·상태. 먼저 보여 줄 정보(T/F로 판단할 값 등)나 우리말 뜻은 문장 칸에서 줄을 바꿔(Alt+Enter) 문제 문장 위에 쓴다: 그 탭의 표시(괄호 보기, [ ], [틀린 말 → 고친 말])가 있는 마지막 줄이 문제 문장(표시가 없으면 맨 아래 줄)이고, 나머지 줄은 쓴 순서대로 문장 위에 한 줄씩 나온다. 우리말 칸은 배열 탭에만 있다(우리말 뜻이 유일한 단서라서). 예전 파일의 우리말 칸은 다른 탭에서도 그대로 읽고, [엑셀로 받기]에서는 문장 칸의 윗줄로 옮겨 쓴다. 머리글 바로 아래 연한 파란 예시 줄은 문제로 내지 않는다. 앱이 템플릿의 예시 내용(grammar.ts TEMPLATE_EXAMPLES, 지난 템플릿의 예시 포함)으로 알아보므로 표시 칸이 필요 없고, 내용을 고치면 그 줄은 문제가 된다. 그 아래에 예시와 같은 줄(복사만 하고 안 고친 줄)이 있으면 내지 않되 줄 번호와 함께 경고한다. 예전 템플릿처럼 번호 칸이 있고 '예시'라고 쓰인 줄도 예시로 본다. 시트 보호는 걸지 않는다(AI 도구가 새로 쓴 칸이 잠긴 칸이 되어 엑셀에서 고칠 수 없게 되므로). 지시문·해설만 있는 줄(아래로 채워 둔 지시문)은 건너뛰고 탭마다 경고 하나로 알린다.

| 탭 | 쓰는 법 | 나오는 모양 | 기본 시간 |
|---|---|---|---|
| 문법 고르기 | 문장에 `(try / to try)`(2~4개, 정답은 그 말이나 번호) · 보기1~4에 문장(정답은 번호, 문장 칸엔 '어법상 바른 문장을 고르세요.' 같은 질문: 한글 문장은 지시문이 비었으면 질문으로, 지시문이 있으면 보기 위 정보로 나온다) · 정답이 O/X(T/F)면 OX | 운동장 2~4칸. 괄호 보기는 정답 칸을 섞고, 문장 보기는 선생님 순서 그대로(해설의 '②번'이 맞게). 문장 보기는 프로젝터·폰에 ①②로 나열하고 칸에는 다른 부분만(`to clean` / `clean`), 다른 부분이 길면(28자 넘게) 번호만 | 15초(문장 보기는 10초 + 문장마다 8초: 2개 26초, 4개 42초) |
| 문법 쓰기 | 답 자리를 `[let]`로(4개까지, 다른 답은 `[as\|so]`나 `[as/so]`). `[ ]`가 없으면 정답 칸(다른 답은 `\|`, `/`는 답의 일부로 읽고 경고) | 폰에 빈칸마다 입력칸(①②…, 엔터로 다음 칸) 또는 한 줄 | 빈칸 20초 + 칸마다 5초(최대 40), 한 줄 40초 |
| 문법 고치기 | 틀린 곳을 `[fastly → fast]`로(→ -> => 모두, 다른 답은 `[to cross → cross\|crossing]`). 빼야 하는 말은 `[to →]`. 헷갈리게 할 곳은 `[runs]`로 표시(선택, 틀린 곳까지 4곳까지, 넘으면 오류) | 두 문제: ① 운동장에서 틀린 곳 찾기(후보 4곳에 ①~④ 밑줄, 표시한 곳이 모자라면 앱이 문장의 다른 낱말에서 채움: a/an/the, 두 번 나오는 낱말, 틀린 말과 같은 낱말은 빼고) ② 폰에 고쳐 쓰기(고친 말, '틀린 말 → 고친 말', 고친 문장 전체 모두 정답). 빼는 문제는 찾기 한 문제만(공개 때 해설). 찾기의 정답은 폰에 '틀린 곳'으로 줄을 그어 보여 주고, 오답 노트에는 'fastly → fast'로 | 찾기 15초, 고쳐 쓰기 20초 |
| 문법 배열 | 정답 문장을 조각마다 `/`로(3~12조각), 첫 조각도 소문자로. 우리말 칸에 뜻. 다른 순서도 맞으면 `\|` 뒤에 같은 조각으로 | 폰에서 섞인 조각을 순서대로 누름(누른 조각을 누르면 되돌림, [다시 놓기]). 조각에는 끝의 . ? !를 빼고(문장부호만 있는 조각은 앞 조각에 붙임), 첫 조각이 The·This·My 같은 흔한 낱말로 대문자 시작이면 소문자로 바꾼다(이름과 I는 그대로). 완성 문장은 첫 글자를 대문자로, 끝은 선생님이 쓴 . ? !(없으면 .) | 15초 + 조각마다 2초(20~45) |

- 채점(쓰기·고쳐 쓰기·배열): 대소문자, 끝의 . ? !, 쉼표, 굽은 따옴표, 줄임말(didn't = did not, can't = can not)은 같게 본다. 철자는 정확해야 한다. 빈칸 여러 개는 칸을 이어 붙인 낱말 순서로 보되(다음 칸에 쓴 낱말도 인정), 빈칸마다 그 빈칸의 다른 답 중 무엇이든 맞다.
- 공개: 빈칸·괄호는 정답이 초록으로 채워지고, 고쳐 쓰기는 틀린 말에 빨간 줄과 고친 말, 배열은 완성 문장, 문장 보기는 정답 문장이 초록으로 켜진다. 해설은 맞든 틀리든 폰에도 나온다. 오답 노트와 다시 풀기에는 우리말·밑줄·빈칸이 함께 나오고, 노트에 해설이 '규칙'으로 붙는다.
- 문법은 단어처럼 정답률·오늘의 보상·연속 정답에 들어간다. 다시 도전은 단어만. 오답 노트에는 문법 문제도 들어간다(문제와 정답).
- 문제 ID는 `g:` + 줄 내용의 해시(고치기는 `:find`/`:fix`). 같은 파일에 같은 줄이 또 있으면 뒤의 것은 건너뛴다.
- [엑셀로 받기]는 문법 줄을 올린 그대로(칸 값 그대로) 각 탭의 예시 줄 아래에 쓴다.

### `문항` 시트 (예전 파일만)

템플릿에서는 뺐다(객관식·OX는 문법 고르기, 단답형은 문법 쓰기로 같은 문제를 만들 수 있고, 그쪽은 점수에 들어간다). 예전 파일에 문항 시트가 있으면 그대로 읽는다. [엑셀로 받기]는 이 문제들을 문법 고르기(객관식: 문제는 지시문, 보기1~4 / OX: 문장)와 문법 쓰기(단답형)에 써서, 다시 올리면 점수에 들어가는 문법 문제가 된다(보기별 피드백은 빠진다). 유형 객관식 / OX / 단답형, 정답·해설·피드백1~4·시간(초)을 직접 쓴다. 문항ID는 비워도 된다(비우면 앱이 유형·문제·보기·정답으로 정하고, [엑셀로 받기]는 그 칸을 다시 비워 둔다). 문항ID 없이 내용이 같은 줄이 같은 세트에 또 있으면 뒤의 것은 경고와 함께 건너뛴다(앞의 것이 검토·보관이고 뒤의 것이 사용이면 뒤의 것을 쓴다). 원정 끝에 나오고, 객관식·OX는 운동장 칸으로, 단답형은 폰 입력으로 낸다. 단답형 정답이 여러 개면 `|`로. 직접 쓴 문항은 보너스라 정답률·보상·다시 도전·연속 정답에서 뺀다.

### 명단

학생 명단은 보통 단어 파일에 넣지 않는다 (예시 이름이 섞이거나 동료와 파일을 나눌 때 이름이 퍼지지 않게). 선생님 화면 [반 관리]에서 반을 만든다. 명단은 학생이 처음 접속해 직접 등록하면서 채워지고, 원하면 반마다 '번호 이름'을 미리 붙여 넣어 등록 요청과 맞춰 볼 수 있다. 다른 반 명단은 건드리지 않는다. 학기 말이나 폰 교체 때는 [이 반 기기 모두 해제]로 반 전체를 다시 등록하게 할 수 있다 (기록·캐릭터는 유지). 엑셀에 '명단' 시트(반·번호·이름)가 있으면 빈 번호만 반별로 채운다. 이미 다른 이름이 있는 번호는 바꾸지 않고 미리보기에 경고로 알려 준다.

### 검증

- 행 번호와 함께 알려 준다. 오류는 고쳐야 이벤트를 만들 수 있다: 단어·뜻 빈칸, 영어가 아닌 단어, 문법 탭에서 표시가 없거나 정답과 맞지 않는 줄, 문항 시트의 빈 칸·잘못된 유형·정답. 경고는 그대로 만들 수 있다: 모르는 머리글(영어·의미처럼 흔한 다른 이름은 받아 줌), 같은 단어 중복(뒤의 것은 건너뜀), 예문 빈칸을 못 만드는 이유, 날짜·시간으로 바뀐 칸, 시간 5~60 밖(기본값으로).
- 정답 칸은 텍스트로 읽는다. ①·1)·(1) 같은 기호와 o·○·×도 받아 준다.
- `검토` 상태는 저장만 하고 출제하지 않는다. `보관`은 오답 보기로도 쓰지 않는다.

## 5. 데이터

모두 노트북의 `.data/classeum.json` 한 파일에 둔다.

- **반**: 이름
- **학생**: 반, 번호(반 안에서), 이름, 캐릭터(머리 모양·색·착용 아이템), 보유 아이템
- **기기**: 기기 토큰(해시) → 학생, 마지막 접속
- **등록 요청**: 반·번호·이름, 명단과 비교한 종류, 확인 기호, 상태(대기·승인·거절·만료)
- **단어**: 단어키, 철자, 뜻, 품사, 헷갈리는 단어, 예문, 상태
- **이벤트**: 이름, 날짜, 문항 순서(실제 보기와 정답 위치까지 고정), 다시 도전 문항, 오늘의 보상, 원본 파일 이름
- **세션 기록**: 이벤트, 반, 시각, 학생별 접속 문항 수·정답 수·보상 판정 여부
- **응답**: 세션, 문항, 학생, 라운드, 고른 칸(또는 쓴 답), 정오, 시각
- **보상 기록**: 학생, 아이템, 이유(도전·성장·출석), 날짜
- **출석**: 학생별 날짜
- **지난 결과**: 학생별 마지막 퀴즈 결과와 오답 노트

## 6. 기술 구성

- 선생님 노트북 한 대가 서버다. Next.js 웹앱을 `npm run class`로 켠다(바뀐 게 있을 때만 next build, 그다음 next start). 같은 와이파이의 폰이 노트북 주소로 접속한다.
- 실시간: 서버 → 화면은 SSE, 폰·선생님 → 서버는 fetch POST. 서버는 화면마다 직전과 같은 내용은 다시 보내지 않는다.
- 끊김 대비: 서버가 10초마다 ping을 보내고, 화면이 보이는 폰은 25초 동안 아무것도 못 받으면 스스로 다시 연결한다(와이파이가 돌아오면 바로). 폰은 화면이 보이는 동안 15초마다 신호를 보내고, 40초 넘게 신호가 없는 폰은 접속에서 뺀다(잠근 폰이 조기 마감을 막지 않게). 폰 요청은 5초 안에 답이 없으면 실패로 보고 다시 보낸다. 연결은 65초까지 재사용한다.
- 기록 파일에서 응답은 사전(문항·학생 ID 목록) + 숫자 배열로 압축해 저장한다(응답 하나 약 12바이트, 메모리에서는 평소 객체). `npm run class`는 next dev가 남긴 `.next/dev`를 지운다.
- 진행 엔진(시계, 마감 판정, 보상)은 서버(`src/server/hub.ts`)가 돌린다.
- 저장은 JSON 파일 하나(`.data/classeum.json`). 파일 전체를 쓴 뒤 바꿔 끼워서 정전에도 이전 것이나 새 것 중 하나가 남는다. 읽지 못하는 파일이 있으면 덮어쓰지 않고 서버를 켜지 않는다.
- 계정 없음. 선생님 화면과 프로젝터는 터미널에 나온 선생님 링크가 주는 쿠키(`.data/teacher-key`)로, 학생은 서버가 준 기기 쿠키와 선생님 승인으로 구분한다.
- http라서 홈 화면 설치·화면 꺼짐 방지(Wake Lock)는 쓰지 않는다. 학생에게 화면 꺼짐 시간을 늘리도록 안내한다.

## 7. 개인정보 (방과후 기준)

- 방과후·동아리 수업이라 학운위 심의 대상은 아니지만 개인정보 동의는 필요하다.
- 저장: 번호, 이름, 퀴즈 기록, 캐릭터. 연락처·생년월일·사진·성별은 받지 않는다.
- 만 14세 미만 학생이 있으므로 보호자 동의서를 전원에게 받는다 (서면).
- 데이터는 선생님 노트북에만 있다 (외부 서버·국외 이전 없음).
- 학기 말에 내보내기 후 삭제한다.
