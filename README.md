# Classeum

운동장에서 함께 푸는 영단어 퀴즈. 선생님 노트북이 서버가 되고, 학생은 각자 폰으로 접속합니다.

- 기획서: [docs/PLAN.md](docs/PLAN.md)
- 엑셀 예시: [templates/](templates/) (단어장 시트에 단어·뜻만 쓰면 문제가 자동으로 만들어져요)

## 수업 전에 한 번

```bash
npm install
```

## 매주 수업

1. 노트북과 학생 폰을 **같은 와이파이**에 연결합니다.
2. 서버를 켭니다.

   ```bash
   npm run class
   ```

   개발 중에는 `npm run dev`를 써도 됩니다.
3. 노트북 브라우저에서 `http://localhost:3000/teacher`를 엽니다. (반드시 `localhost` 주소로 여세요.)
   - 처음 연 브라우저가 선생님 브라우저로 등록돼요. 학생이 같은 와이파이에서 주소를 흉내 내도 선생님 화면은 열리지 않아요.
   - 다른 브라우저에서 열어야 하면, 서버를 켠 터미널에 나온 **선생님 링크**(`.../api/teacher/login?key=…`)를 그 브라우저에서 여세요. 이 링크는 남에게 보여 주지 마세요.
4. 프로젝터를 **확장 모드**로 연결하고, [프로젝터 화면 열기]로 뜬 창을 프로젝터 쪽으로 옮겨 `F` 키로 전체 화면을 만듭니다.
5. [엑셀 올리기] → 미리보기 확인 → [이벤트 만들기] → 보상 고르기 → [대기실 열기].
6. 학생은 큰 화면의 QR을 찍고 들어옵니다. 처음 온 학생은 이름을 고르면 선생님 화면 오른쪽에 등록 요청이 뜹니다(접어 둘 수 있어요). 확인 기호가 같은지 보고 승인하세요.
   - 아이폰은 사파리에서 그대로 쓰세요. "홈 화면에 추가"로 연 앱은 사파리와 기기 정보가 달라 다시 등록해야 해요.
7. [퀴즈 시작].

### 진행 중 단축키 (선생님 화면, 프로젝터 화면 모두)

| 키 | 동작 |
|---|---|
| Space | 멈춤 / 다시 시작 |
| Enter | 지금 정답 공개 |
| ↑ | +5초 |
| S | 건너뛰기 |
| → | 다음 (자동 진행을 껐을 때) |
| B | 화면 가리기 (시계도 멈춤) |
| F | 프로젝터 화면에서 전체 화면 |

한글 입력 상태에서도 S, B가 그대로 먹어요. 화면을 가리면(B) 모든 시계가 멈추고, 다시 누르면 이어서 진행해요.

## 접속이 안 될 때

- 학교 와이파이가 기기끼리 통신을 막는 경우가 많아요. 그럴 땐 **40대 이상 받는 휴대용 공유기**에 노트북과 학생 폰을 모두 연결하세요. 휴대폰 핫스팟은 보통 10대 안팎이라 반 전체를 받지 못해요.
- 노트북 방화벽이 3000번 포트를 막지 않는지 확인하세요 (macOS: 시스템 설정 → 네트워크 → 방화벽).
- 공유기에서 노트북 IP를 고정(예약)해 두면 매주 같은 주소라서 학생 폰이 그대로 자동 입장해요.
- 수업 전에 폰 2~3대로 미리 접속해 보세요. `npm run sim -- 30`으로 가짜 학생 30명을 붙여 흐름을 시험할 수도 있어요.
- 노트북 절전·화면 보호기를 끄고 전원을 연결해 두세요.

## 데이터

- 모든 기록은 노트북의 `.data/classeum.json`에 저장돼요. 이 파일은 git에 올라가지 않아요 (학생 이름이 들어 있으므로).
- 학생 정보는 번호, 이름, 퀴즈 기록, 캐릭터만 저장해요.
- [통계] → [엑셀로 내보내기]로 학생별 기록을 받을 수 있어요.
- 학생마다 마지막 퀴즈의 오답 노트가 남아서, 아레나를 닫은 뒤에도 폰 첫 화면의 [지난 오답 노트]에서 다시 보고 풀 수 있어요.
- `.data/teacher-key`는 선생님 링크의 열쇠예요. 지우면 다음 서버 실행 때 새로 만들어지고, 처음 여는 브라우저가 다시 선생님이 돼요 (`.data/teacher-claimed`도 같이 지우세요).

## 구조

```
src/
  app/
    teacher/   선생님 노트북 화면 (이벤트, 진행 콘솔, 학생·기기, 통계)
    display/   프로젝터 화면 (대기실, 운동장, 마무리)
    play/      학생 폰 화면 (등록, 캐릭터, 게임 패드, 결과, 오답 노트, 보관함)
    api/       stream(SSE) · action · upload · stats · device
  server/
    excel.ts     엑셀 읽기·검증
    generate.ts  단어장 → 문제·오답 보기 자동 생성 (AI 없음)
    hub.ts       진행 엔진: 세션 상태, 시계, 마감 판정, 보상
    store.ts     저장소 (지금은 JSON 파일)
    stats.ts     학생별·단어별 통계
  client/live.ts 실시간 연결 (지금은 SSE + fetch)
  lib/           공용 타입, 픽셀 아바타, 아이템, 문자열 도구
scripts/
  make_vocab_template.py  엑셀 예시 만들기
  preview-event.ts        엑셀로 어떤 문제가 나올지 미리 보기
  sim-students.ts         가짜 학생 시뮬레이터
```

## Vercel + Supabase로 옮기기

지금은 노트북 한 대가 서버 역할을 해요. 인터넷 주소(https)로 옮기면 교실 와이파이 문제가 사라지고 홈 화면 설치·화면 꺼짐 방지도 쓸 수 있어요. 바꿀 곳은 세 군데로 모아 두었어요.

1. `src/server/store.ts`: JSON 파일 대신 Supabase Postgres (서울 리전). 테이블은 기획서 5장의 데이터 목록 그대로입니다.
2. `src/client/live.ts`와 `src/app/api/stream`: SSE 대신 실시간 채널.
3. `src/server/hub.ts`의 진행 엔진: Vercel 함수는 계속 떠 있지 않으므로, 시계를 돌리는 쪽을 따로 정해야 해요 (선생님 노트북 탭이 호스트가 되거나, 작은 실시간 서버를 둠). 조사 결과는 기획서 6장에 정리합니다.

옮기는 주에는 모든 학생이 한 번 다시 등록해야 해요 (주소가 바뀌면 기기 정보도 새로 생기므로). 기록은 학생 단위로 이어집니다.
