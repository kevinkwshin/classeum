# Classeum

운동장에서 함께 푸는 영단어 퀴즈. 선생님 노트북이 서버가 되고, 학생은 각자 폰으로 접속합니다.

- 기획서: [docs/PLAN.md](docs/PLAN.md)
- 엑셀 예시: [templates/](templates/) (단어장 시트에 단어·뜻만 쓰면 문제가 자동으로 만들어져요). 선생님 화면의 [템플릿 받기]는 `7주차_영단어.xlsx`(Lesson 7 단어 44개)를 내려받아요.

## 수업 전에 한 번

```bash
npm install
```

- 폴더는 OneDrive·iCloud로 동기화되는 곳(바탕 화면·문서 폴더가 동기화되는 경우가 많아요) 말고 다른 곳에 두세요. 기록 파일을 문제마다 다시 써서 동기화 앱과 부딪혀요.
- `npm install`을 하거나 새 ZIP으로 바꾼 뒤 처음 `npm run class`는 인터넷이 한 번 필요해요(빌드할 때 글꼴을 받아요).

### 윈도우 노트북이라면

1. [nodejs.org](https://nodejs.org)에서 **LTS** 버전을 설치합니다(기본값 그대로).
2. 이 저장소를 받습니다. GitHub 페이지의 [Code → Download ZIP]으로 받아 압축을 풀거나 `git clone https://github.com/kevinkwshin/classeum.git`.
3. 그 폴더의 **`Classeum.bat`을 더블클릭**하면 검은 창이 뜨고 서버가 켜져요. 처음 한 번은 필요한 파일을 받느라 몇 분 걸려요. 수업이 끝나면 그 창을 닫으면 서버가 꺼져요.
   (명령으로 하려면 그 폴더에서 명령 프롬프트를 열고 `npm install`, 그다음 `npm run class`.)
4. 처음 켤 때 "Windows 보안 경고 · Node.js" 창이 뜨면 **[허용]**을 누릅니다. 학교 와이파이가 '공용 네트워크'로 잡혀 있으면 폰이 들어오지 못해요. 와이파이 속성에서 '개인 네트워크'로 바꾸거나, 그 창에서 공용 네트워크도 체크하세요.
5. 선생님 화면이 저절로 열리는 게 싫으면 PowerShell에서 `$env:CLASSEUM_NO_OPEN=1; npm run class`.

학생 기록(반·명단·캐릭터·출석)은 그 노트북의 `.data` 폴더에만 있고 GitHub에는 올라가지 않아요. 노트북을 바꾸면 `.data` 폴더를 통째로 옮기세요. 노트북이 바뀌거나 와이파이 주소가 바뀌면 학생 폰은 새 기기로 보여서 다시 등록해야 해요. 같은 반·번호·이름으로 보내면 '기기 교체'로 떠서 승인하면 기록이 그대로 이어져요.

처음 쓰는 노트북이면 이벤트 화면 위에 **수업 준비** 카드가 떠서 반 만들기 → 단어 넣기 → 프로젝터 → 폰 접속 → 첫 퀴즈를 하나씩 체크해 줘요. 다 되면 저절로 접히고, [숨기기]로 닫아도 돼요. 왼쪽 메뉴 아래 **?**에는 같은 목록과 수업 중 키, 끝내는 법이 있어요. 대기실의 [놀이 방법]은 프로젝터에 12초짜리 시범을 보여 주고, 처음 온 학생 폰에는 대기 화면에 연습 문제가 하나 떠요(기록에 남지 않아요).

## 매주 수업

1. 노트북과 학생 폰을 **같은 와이파이**에 연결합니다.
2. 서버를 켭니다.

   ```bash
   npm run class
   ```

   개발 중에는 `npm run dev`를 써도 됩니다.
   - 바뀐 게 없으면 빌드를 건너뛰어서 바로 켜져요. 처음이나 업데이트한 뒤에만 빌드하느라 조금 걸려요.
   - 끌 때는 Mac은 터미널에서 `Ctrl+C`, 윈도우는 검은 창을 닫으세요.
   - 예전 Classeum 서버가 켜져 있으면 알아서 끄고 새로 켜요. 퀴즈가 진행 중일 때만 끌지 먼저 물어봐요. 다른 프로그램이 3000번 포트를 쓰고 있으면 빌드 전에 멈추고 알려 줘요.
3. `npm run class`가 노트북 브라우저에 **선생님 화면을 저절로 열어 줘요** (터미널에 나온 선생님 링크 `.../api/teacher/login?key=…`). 한 번 열린 브라우저는 다음부터 `http://localhost:3000/teacher`로 바로 열려요.
   - 다른 브라우저에서 열어야 하면 터미널의 선생님 링크를 그 브라우저에 붙여 넣으세요. 이 링크는 남에게 보여 주지 마세요. 학생이 같은 와이파이에서 주소를 흉내 내도 선생님 화면은 열리지 않아요.
   - 저절로 열리는 게 싫으면 `CLASSEUM_NO_OPEN=1 npm run class`.
4. 프로젝터를 **확장 모드**로 연결하고, [프로젝터 화면 열기]로 뜬 창을 프로젝터 쪽으로 옮겨 `F` 키로 전체 화면을 만듭니다.
5. 처음 한 번: [학생·기기]에서 반을 만드세요(예: 2-3반). 명단은 넣지 않아도 돼요. 학생이 처음 접속해서 직접 등록하면 승인할 때 명단에 들어가요. 미리 넣어 두면 학생이 쓴 이름과 맞춰 보여 줘서 승인이 쉬워요.
6. [엑셀 올리기] → 미리보기 확인 → [이벤트 만들기] → 보상 고르기 → **오늘 반 고르기** → [대기실 열기]. 같은 이벤트를 다른 반에서 또 열 수 있어요.
   - 이벤트 이름은 엑셀 파일 이름이에요([템플릿 받기]로 받으면 `7주차_영단어`). 시간 칸이 비면 문항당 10초예요.
   - 엑셀 없이 [직접 작성하기]로 제목과 단어·뜻(예문은 선택)을 바로 써도 돼요. 엑셀이나 한글 표에서 여러 줄을 복사해 붙여 넣으면 칸이 채워지고, Enter는 아랫줄로 가요. 쓰던 내용은 이 노트북에 저장돼서 창을 닫아도 남아요. 이벤트 이름은 제목이에요.
   - 이벤트 목록과 상세에 반 이름이 나와요. 초록은 그 퀴즈를 한 반, 회색은 아직 안 한 반이에요(마우스를 올리면 날짜·정답률). 고른 반이 이미 했으면 대기실 열기 전에 알려 줘요.
7. 학생은 큰 화면의 QR을 찍고 들어옵니다. 처음 온 학생은 **반·번호·이름을 직접 쓰고** [등록 요청]을 누르면, 선생님 화면 오른쪽에 요청이 뜹니다(접어 둘 수 있어요). 확인 기호가 같은지 보고 승인하세요.
   - 요청 옆 표시: **명단 확인**(명단과 같음) · **새 학생**(명단에 없음, 승인하면 추가) · **기기 교체**(이미 등록한 학생의 새 폰) · **번호 겹침**(그 번호에 다른 이름이 있음).
   - 아이폰은 사파리에서 그대로 쓰세요. "홈 화면에 추가"로 연 앱은 사파리와 기기 정보가 달라 다시 등록해야 해요.
   - 등록은 선생님 화면이나 프로젝터 화면이 켜져 있을 때만 돼요. 등록 전 폰에는 다른 학생 이름이 하나도 보이지 않아요.
   - 대기실이 열려 있으면 그 반 이름만 보여요. 다른 반 학생 폰은 "지금은 ○반 수업 중"이라고만 나와요.
   - [모두 승인]은 명단 확인과 새 학생을 한 번에 승인해요. 기기 교체, 번호 겹침, 같은 이름이 다른 번호에 있는 요청에는 '따로 확인'이 붙어요. 이런 요청은 하나씩 보고 승인하세요. 같은 학생이 번호를 잘못 쓴 거라면 거절하고 원래 번호로 다시 보내게 하세요.
   - 학생이 대기 화면을 보고 있는 동안에는 요청이 사라지지 않아요. 폰을 끄거나 나가면 2분 뒤 사라지고, 길어도 15분이면 사라져요.
8. [퀴즈 시작]. 끝나면 [아레나 닫기]로 모든 폰을 대기 화면으로 돌려보내요.
   - 대기실과 정답 공개 때 프로젝터에 학생 이름이 나와요. 부담스러운 날은 대기실이나 진행 화면의 [이름표] 체크를 끄세요.
   - 정답 공개 때 맞힌 학생이 있으면 프로젝터에서 "Yeah!" 소리가 나요(많이 맞힐수록 커요). 아무도 못 맞히면 잠깐 뒤 귀뚜라미 소리가 2초 나요. 브라우저 규칙 때문에 프로젝터 창을 **한 번 클릭하거나 F를 눌러야** 소리가 켜져요. 끄려면 [효과음] 체크를 푸세요. 다시 켜면 한 번 들려줘서 소리 크기를 맞출 수 있어요.
   - 퀴즈가 끝나면 바로 결과로 넘어가요. 많이 틀린 단어를 한 번 더 풀게 하고 싶은 날은 이벤트 화면에서 [끝나고 많이 틀린 단어 다시 풀기]를 켜세요.
   - 학생 폰에는 정답 공개 때 맞힌 친구 캐릭터(이름 없이)와 나만 보는 연속 정답(🔥 N연속)이 나와요.
   - 학생은 처음 들어올 때 캐릭터를 골라요(머리 모양 12·머리색 7·피부 4·눈 5가지). 나중에 보관함의 [머리·눈 바꾸기]로 바꿀 수 있고, 아이템은 그대로예요.
   - 도중에 [종료]를 누르면 지금까지 푼 문제로 결과가 저장돼요. 낱말 문제의 절반도 안 풀었으면 그날은 보상 판정을 하지 않아요.

### 진행 중 단축키 (선생님 화면, 프로젝터 화면 모두)

| 키 | 동작 |
|---|---|
| Space | 멈춤 / 다시 시작 |
| Enter | 지금 정답 공개 |
| ↑ | +5초 |
| S | 건너뛰기 |
| → | 다음 (자동 진행을 껐을 때) |
| B | 화면 가리기 (시계도 멈춤) |
| F | 프로젝터 화면에서 전체 화면 |

한글 입력 상태에서도 S, B가 그대로 먹어요. 화면을 가리면(B) 모든 시계가 멈추고, 다시 누르면 이어서 진행해요.

## 접속이 안 될 때

- 학교 와이파이가 기기끼리 통신을 막는 경우가 많아요. 그럴 땐 **40대 이상 받는 휴대용 공유기**에 노트북과 학생 폰을 모두 연결하세요. 휴대폰 핫스팟은 보통 10대 안팎이라 반 전체를 받지 못해요.
- 노트북 방화벽이 3000번 포트를 막지 않는지 확인하세요 (macOS: 시스템 설정 → 네트워크 → 방화벽).
- 공유기에서 노트북 IP를 고정(예약)해 두면 매주 같은 주소라서 학생 폰이 그대로 자동 입장해요.
- 수업 전에 폰 2~3대로 미리 접속해 보세요. `npm run sim -- 30`으로 가짜 학생 30명을 붙여 흐름을 시험할 수도 있어요.
- 노트북 절전·화면 보호기를 끄고 전원을 연결해 두세요.

## 데이터

- 모든 기록은 노트북의 `.data/classeum.json`에 저장돼요. 이 파일은 git에 올라가지 않아요 (학생 이름이 들어 있으므로).
- 기록 파일이 망가져 있으면 빈 기록으로 덮어쓰지 않고 서버를 켜지 않아요. 망가진 파일은 `classeum.json.broken-…`으로 남겨요.
- 학생 정보는 번호, 이름, 퀴즈 기록, 캐릭터만 저장해요.
- [통계]의 [이 반 엑셀로]·[전체 엑셀로]로 학생별 기록을 받을 수 있어요.
- 학생마다 마지막 퀴즈의 오답 노트가 남아서, 아레나를 닫은 뒤에도 폰 첫 화면의 [지난 오답 노트]에서 다시 보고 풀 수 있어요.
- `.data/teacher-key`는 선생님 링크의 열쇠예요. 링크가 퍼졌다면 이 파일을 지우고 서버를 다시 켜세요. 새 열쇠가 만들어지고 예전 링크와 쿠키는 더 이상 통하지 않아요.

## Vercel + Supabase로 옮기기

지금은 노트북 한 대가 서버 역할을 해요. 인터넷 주소(https)로 옮기면 교실 와이파이 문제가 사라지고 홈 화면 설치·화면 꺼짐 방지도 쓸 수 있어요. 바꿀 곳은 세 군데로 모아 두었어요.

1. `src/server/store.ts`: JSON 파일 대신 Supabase Postgres (서울 리전). 테이블은 기획서 5장의 데이터 목록 그대로입니다.
2. `src/client/live.ts`와 `src/app/api/stream`: SSE 대신 실시간 채널.
3. `src/server/hub.ts`의 진행 엔진: Vercel 함수는 계속 떠 있지 않으므로, 시계를 돌리는 쪽을 따로 정해야 해요 (선생님 노트북 탭이 호스트가 되거나, 작은 실시간 서버를 둠). 조사 결과는 기획서 6장에 정리합니다.
